Chapter 4 "When & where" (b): real map of Australia + linked trend

Real state outlines (ABS 2021, equal-area projection), shaded per 100,000 (5 classes); the ACT is enlarged in a box. Click a state -> ranking (page 09b).

Redraws on: mapGroup, mapState, mapView, width, theme, cvd

  1. 1 Prompt answers half (NT) and teases the other half (ACT for cyclists)
  2. 2 Road-user chips + Map | Ranking chips (always visible: the ranking can be found without clicking the map)
  3. 3 Real outlines, equal-area conic projection (sizes stay honest); selected state = ink outline
  4. 4 ACT is ~0.03% of the area (4x7 px): enlarged in a box + dashed leader; the box is the ACT's button
  5. 5 Labels: code + rate on each state; Tas beside the island, Vic on one line (too small for two)
  6. 6 Tab = one stop, arrow keys move state to state, Enter -> ranking; focus = yellow ring (here Vic)
  7. 7 Click / Enter a state: morph to the ranking, see page 09b
  8. 8 Linked trend: selected state (solid) vs Australia (dashed), COVID shaded
  9. 9 Table: every state + Australia; take-away names highest + lowest

Chapter 4 (b) continued: map -> ranking morph, and the ranking view

Clicking a state turns the map into a ranked bar chart; each state stays the same object, so the eye can follow it. Back / Esc / chips reverse it.

Redraws on: mapGroup, mapState, mapView ("map" | "bars")

  1. 1 Click / Enter on a state = select it AND switch to the ranking {mapState: WA, mapView: bars}
  2. 2 Each state is ONE group: its shape fades while a box from the state's bounds grows into its bar
  3. 3 "← Back to map" only in this view; Esc and the Map chip do the same; focus goes back to the state
  4. 4 Selected bar: ink outline, bold value; screen reader: "rank 7 of 8"
  5. 5 Zero baseline + dashed Australia line: bars compare honestly
  6. 6 Tab = one stop, ↑ ↓ between bars, focus ring + tooltip + announcer
  7. 7 Legend and hint change with the view; <title>/<desc> rewritten and announced ("ranked 7 of 8")
  8. 8 Click another bar: only the trend changes {mapState}; the ranking stays (no re-animation)
