# Usability evaluation (Design Book §4.2)

Required by the brief: conduct and document a usability evaluation using appropriate methods.

## Files to add here
- `test-plan.md` — goals, method (e.g. think-aloud task-based test + SUS questionnaire), participants (5 is enough), setting
- `tasks.md` — tasks with expected answers (use the explanatory/exploratory question table, e.g. "Which road user group grew fastest?" → pedal cyclists)
- `consent-form.md`
- `results/round-1.md`, `results/round-2.md` — raw notes, task success, time, errors, SUS scores
- `findings.md` — issues found → changes made → before/after screenshots (link to PRs)

## Accessibility checks to record
- Colour-vision deficiency simulation of every palette
- Text/background contrast ratios
- Keyboard-only navigation through all interactions
- Screen-reader labels (ARIA) on charts
